雅思短语 PWA v4

本版新增：
1. 只有完整完成一轮测试后，结果页才提供“保存本轮记录”；中途退出不会保存。
2. 测试中途点返回会明确提示“退出不会保存历史记录”；刷新/关闭页面也会触发浏览器离开提醒。
3. 历史记录保存成绩、模式、模块和完整错题数据；以后可直接点击“复习错题”重新测试。
4. 旧版只保存分数、未保存错题详情的历史记录仍会显示，但无法生成错题复习。
5. 新增小型“检测到新版本，点击立即更新”提示。更新由用户确认后切换，避免突然刷新打断测试。
6. 保留 v3 的灵活词形识别、IELTS 中文造句提示、单条/单模块掌握重置及 PWA 安装优化。

部署：覆盖旧仓库文件后执行：
git add .
git commit -m "Add saved test history wrong-answer review and update prompt"
git push

GitHub Pages 地址不变。
