雅思短语 PWA v2

部署后直接打开 index.html 所在网址。

本版更新：
1. 造句识别更灵活：支持常见三单、过去式、过去分词、-ing、单复数、one's/其具体所有格等合理变化。
2. 修复情态动词规则误判（例如 can access 不会再因 access 以 s 结尾而被误报）。
3. 造句新增“中文翻译提示”：需要时显示 IELTS 大作文风格中文句子，再翻译成英文。
4. 学习中心支持单条取消掌握、单模块重置、全部重置。
5. PWA 图标增加 192/512 PNG，提升 Chrome/Edge/Android 安装兼容性。
6. 离线缓存版本升级为 v2。

iPad/iPhone：Safari → 分享 → 添加到主屏幕。
Mac Safari：文件 → 添加到程序坞。
Chrome/Edge/Android：如浏览器支持，可直接安装应用。
首次加载需要联网，之后学习/测试可离线。
